USB 切换与扩展

双主机四口 USB 2.0 切换 Hub

一款四口 USB 2.0 Hub，可通过按键在两台主机之间切换，让两台电脑共享同一组 USB 外设。

双主机输入四路 USB 输出USB 2.0DC 供电

双主机输入

IN1 和 IN2 可连接两台主机电脑。

四个下游接口

四个 USB-A OUT 接口用于连接共享 USB 外设。

按键切换

板载按键用于选择当前控制外设的主机。

USB 2.0 Hub

GL850G Hub 电路将选中的上游连接扩展为四个端口。

独立电源输入

DCIN 可独立为 Hub 和所连接外设供电。

电源转换

NB679 同步降压电路从 DC 输入产生大电流 5V 电源。

高速信号切换

USB 高速多路复用器将所选主机的数据线连接到 Hub。

保护与生产文件

包含各端口 ESD 保护、BOM、OrCAD、Allegro PCB 和 Gerber。
