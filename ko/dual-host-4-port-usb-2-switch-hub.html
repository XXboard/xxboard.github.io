듀얼 호스트 4포트 USB 2.0 스위치 허브

버튼으로 두 컴퓨터 사이를 전환하여 동일한 USB 장치를 공유하는 4포트 USB 2.0 허브입니다.

듀얼 호스트4포트USB 2.0DC 전원

두 호스트 입력

IN1과 IN2에 두 대의 호스트를 연결합니다.

네 개의 출력 포트

4개의 USB-A OUT에 공유 주변기기를 연결합니다.

버튼 전환

온보드 버튼으로 장치를 제어할 호스트를 선택합니다.

USB 2.0 허브

GL850G 기반 회로가 선택된 입력을 4포트로 확장합니다.

외부 전원

DCIN으로 허브와 주변기기에 독립적으로 전원을 공급합니다.

전원 변환

NB679 동기식 벅 회로가 고전류 5V 레일을 제공합니다.

신호 전환

고속 USB 멀티플렉서가 선택 호스트를 허브에 연결합니다.

오픈 생산 파일

ESD 보호, BOM, OrCAD, Allegro PCB 및 Gerber를 포함합니다.
