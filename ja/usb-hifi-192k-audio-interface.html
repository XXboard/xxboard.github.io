USB オーディオ

USB Hi-Fi 192K オーディオインターフェース

USB オーディオコントローラー、ステレオ DAC／ADC、MEMS マイク、アナログ出力を統合したオープンハードウェアです。

SA9227 AK4430 AK5720 192 kHz 設計

USB と I²S

SA9227 が USB 接続と I²S ストリームを処理します。

DAC と ADC

AK4430 ステレオ DAC と AK5720 ステレオ ADC を搭載します。

マイクと操作

MEMS マイク、再生、音量＋／－キーを備えます。

電源と保護

3.3V／1.8V 電源、フィルター、USB ESD 保護を備えます。

設計ファイル

OrCAD、Allegro、BOM、Gerber、ドリル、DXF があります。

状態

最終 PCB は DRC／DB エラーゼロ。192 kHz と音質は公開実測が必要です。
