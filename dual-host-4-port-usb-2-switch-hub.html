USB Switching & Expansion

Dual-Host 4-Port USB 2.0 Switch Hub

A four-port USB 2.0 hub that lets two host computers share the same connected USB devices through a pushbutton host selector.

2 Host Inputs4 USB OutputsUSB 2.0DC Power

Two host inputs

IN1 and IN2 connect two host computers to the shared hub.

Four downstream ports

Four USB-A OUT connectors support shared USB peripherals.

Pushbutton switching

The onboard switch selects which host controls the connected devices.

USB 2.0 hub controller

A GL850G-based hub section expands the selected upstream connection to four ports.

External power input

The DCIN connector supplies the hub and attached peripherals independently from the host.

Power conversion

An NB679 synchronous buck stage provides a high-current 5V rail from the DC input.

Signal switching

A high-speed USB multiplexer routes the selected host data pair to the hub controller.

Protection and production files

Per-port ESD protection, BOM, OrCAD, Allegro PCB and Gerber files are included.
