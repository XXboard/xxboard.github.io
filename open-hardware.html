Submission Guidelines

Image and file requirements for open hardware projects.

To keep XXboard projects easy to browse, download, and manufacture, please prepare clear images, documentation, source files, and manufacturing files before submitting a project.

Project cover image

Recommended 1200 × 800 px, 3:2 ratio, WebP / JPG / PNG, preferably under 500 KB and no more than 1 MB.

Gallery images

Recommended 1600 × 1000 px, WebP / JPG / PNG, no more than 2 MB per image. Use photos, renders, PCB screenshots, or assembly views.

Social preview image

Recommended 1200 × 630 px for sharing on social platforms, GitHub, chat apps, and link previews.

Documentation

README.md is required. PDF documentation should preferably be under 10 MB and include overview, features, pinout, usage, and build notes.

Hardware files

Recommended folders: /hardware, /images, /docs, /firmware, /mechanical. Gerber ZIP should preferably be under 20 MB.

Source file limits

KiCad / Altium / CAD source files should preferably stay under 50 MB. Avoid files over 100 MB; use external links for large videos or datasets.

Suggested repository structure: README.md, /images, /docs, /hardware, /firmware, /mechanical, and LICENSE. Please include the project license, current status, and repository link when submitting.
