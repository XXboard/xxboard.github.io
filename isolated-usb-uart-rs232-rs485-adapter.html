Serial Interface Tool

Isolated USB UART RS232 RS485 Adapter

A multi-protocol USB serial debugging adapter with 3.3V TTL UART, RS232 and RS485 interfaces, hardware isolation and a physical mode selector.

USB UARTRS232RS485Isolation

FT234XD USB UART

The FT234XD provides the USB-to-UART bridge for host communication.

3.3V TTL UART

The header exposes GND, 3.3V, TX, RX, CTS and RTS signals for embedded debugging.

RS232 interface

A MAX3232-family transceiver provides RS232-level transmit and receive signals.

RS485 interface

A MAX13487E transceiver provides half-duplex RS485 communication with A and B connections.

Galvanic isolation

High-speed optocouplers and an isolated DC/DC power module separate field-side serial signals.

Hardware protection

The RS485 section includes dedicated transient protection for harsh wiring environments.

Mode selection

An onboard slide switch selects the required serial interface operating mode.

Open design files

The repository provides editable OrCAD schematic and Allegro PCB source files.
